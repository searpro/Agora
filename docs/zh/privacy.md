# 隐私与安全

Agora 是 BYOK 客户端，不运营聊天补全中转服务：请求从设备直接发往你配置的提供商、模型服务器或工具端点。

## 设备上的数据

对话、消息树、任务、循环、记忆、提示词、附件和工具媒体保存在应用管理的数据库/文件中。普通设置使用 Android 偏好。机密通常使用 Android Keystore 支持的 AES-256-GCM 封装；旧明文仍可读取，加密失败时会为避免丢失数据而回退为明文。

## 数据何时离开设备

应用发起的网络请求仅发送到你配置的模型提供商和 MCP 服务器：

- 聊天、标题、转录、图片生成、嵌入和提供商原生搜索请求发往所选模型提供商或配置的端点
- MCP 调用仅发往已启用的 MCP 服务器

应用不会收集崩溃报告、检查更新、提交评分、运行独立网络搜索、获取远程预览资源，也不会联系 Agora 自有的分析或服务端点。提供商和 MCP 服务有各自的隐私与保留政策。

## 备份、代理与传输

`.agora` 是 ZIP 归档；若明确包含 API Key/机密，这些值在归档内部未加密。网络代理只覆盖提供商和 MCP 的 HTTP 流量，不覆盖设备端推理或沙盒进程网络。

发送敏感内容前请核对端点、证书、服务条款和工具权限。
